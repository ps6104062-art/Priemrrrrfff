# 📱 TG Account Receiver Bot

Бот для приёма Telegram аккаунтов с выплатами через CryptoBot.

---

## 🚀 Установка

### 1. Клонировать и установить зависимости
```bash
pip install -r requirements.txt
```

### 2. Настроить переменные окружения
```bash
cp .env.example .env
nano .env  # заполни все поля
```

### 3. Получить данные для Telethon
1. Зайди на https://my.telegram.org
2. Войди со своим номером
3. Перейди в **API development tools**
4. Создай приложение, получи **API_ID** и **API_HASH**
5. Вставь в `.env`

### 4. Запуск
```bash
python bot.py
```

## 🔧 Команды

### Пользователь:
- `/start` — Главное меню

### Админ:
- `/admin` — Панель управления

## 📂 Структура
```
tg_account_bot/
├── bot.py              # Запуск бота
├── config.py           # Конфигурация
├── database.py         # SQLite база данных
├── keyboards.py        # Все клавиатуры
├── handlers/
│   ├── user.py         # Хэндлеры пользователя
│   └── admin.py        # Хэндлеры администратора
└── services/
    ├── telegram_auth.py # Авторизация через Telethon
    └── cryptobot.py    # Выплаты через CryptoBot
```

---

## ⚙️ Функционал

### Пользователь:
- 📱 Сдать аккаунт (+7 номера, с поддержкой 2FA)
- 👤 Профиль: баланс, статистика, история
- 💰 Вывод через CryptoBot чек
- 💬 Ссылка на поддержку

### Админ (`/admin`):
- 📊 Статистика бота
- 👥 Список всех пользователей
- 📱 Управление аккаунтами (одобрить/отклонить)
- 🔑 Слушать коды входа (2 минуты)
- 🔒 Сменить пароль 2FA
- 💸 Обработка заявок на вывод (автоматический CryptoBot чек)

---

## ⚠️ Важно

- Бот принимает **только российские номера** (+7)
- Сессии хранятся в SQLite в виде строк Telethon
- CryptoBot чек создаётся автоматически при выплате
- При отклонении заявки на вывод — баланс возвращается
